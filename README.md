# Clínica Médica Laura Myrna

Sistema de gestão de pacientes com organização por pastas.

## Executar

```
python main.py
```

## Gerar executável

```
pyinstaller --onefile --windowed --name "Clinica_Laura_Myrna" main.py
```

## Funcionalidades

- Cadastro e edição de pacientes
- Organização em pastas/categorias
- Busca por nome, CPF ou telefone
- Histórico clínico e tratamentos
- Banco de dados SQLite

## Backup

Faça backup regular do arquivo `clinica.db`.
